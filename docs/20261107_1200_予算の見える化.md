# 予算の見える化（/budget, /budget/compare）

## ページ
- `/budget`：立川市 令和8年度 一般会計 当初予算の流れ（歳入23款 → 一般会計 → 歳出12款）と、款・項・目・事業（640事業）の中身
- `/budget/compare`：総務省「市町村別決算状況調」（令和6年度・普通会計）による、多摩26市との1人あたり歳出のくらべ（金額／指数の切替、7款の内訳展開）

データは Supabase ではなく `web/src/features/budget/shared/data/` の JSON（静的データ）。AI・APIは使わない。

## 方針（変えないこと）
- 数字は出典資料のまま。名称・担当課も予算書の表記のまま
- 平均より多い／少ないに良し悪しの色を付けない。評価・採点はしない
- 特定の議員・会派・政党を応援・批判しない旨を各ページに明記する
- 理由がわからないものは推測で書かず「確認できなかった」と書く

## データの作り方（毎年の更新手順）

スクリプトは作業用フォルダで実行する前提（PDF・Excel は `raw/` に置く。例：`raw/r8_ippan.pdf`、`raw/gaikyo.xlsx`、`raw/mokuteki.xlsx`）。必要なもの：Python 3、`pdfplumber`、`pdftotext`（poppler）、`openpyxl`。

### 1. 立川市の当初予算（`tachikawa-r8-ippan.json`）
1. 立川市「予算書（当初予算）」ページから「一般会計予算及び事項別明細書」PDF を取得
2. `python3 tools/budget/parse_saishutsu.py <PDF> r8_parsed.json` で歳出の款・項・目・事業を抽出
3. `python3 tools/budget/validate.py r8_parsed.json` で、款→項→目→事業の合計がすべて一致することを確認（予備費のみ事業なしで1件出るのは正常）
4. `python3 tools/budget/parse_dai1hyo.py`（第1表の歳入・歳出の款・項）と `build_data.py`（総括の財源内訳・前年度額を付けて JSON 化）を実行
5. `pnpm --filter web exec vitest run src/features/budget` で `verifyBudget` を含むテストを通す

※ スクリプト内の PDF のページ番号（総括 p.17・18、第1表 p.7〜11）は年度で変わることがあるので確認すること。

### 2. 多摩26市の決算（`tama26-r6-kessan.json`）
1. 総務省「市町村別決算状況調」の都市別「概況」「目的別歳出内訳」の Excel を取得
2. `python3 tools/budget/build_tama26.py` で多摩26市（団体コード 132xxx）を抽出。内訳の合計・歳出総額との一致を確認する
3. 立川市の特殊な支出（例：令和6年度の災害復旧費＝第七中学校体育館復旧事業）は、市の決算説明資料で中身を確認してから注記を書く

## 確認済みの事実（令和6年度決算）
- 災害復旧費 12.1億円：第七中学校体育館の火災からの建て直し（令和7年3月供用開始）。出典：立川市「令和6年度決算説明資料」
- 労働費：総務省統計（普通会計）6.7億円、市の一般会計決算 1.5億円。差の中身は公開資料では未確認
- 幼稚園費：統計上 0円（分類の決まりによるものと考えられる）

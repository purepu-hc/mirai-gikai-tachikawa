# 議員ページ設計（方針と出典）

作成：2026-11-27（運営者と相談して決めた内容を記録）

## 方針の変更（履歴）

| 日付 | 決めたこと | 理由 |
|---|---|---|
| 2026-10 | 議員一覧は自前で作らず、市議会の「50音順議員名簿」へリンクするだけにする | 市議会のページの方が詳しいため |
| 2026-11 | 議員の評価・採点機能（相模原市版のようなもの）は作らない | 公職選挙法・名誉毀損のリスクを検討した結果 |
| **2026-11-27** | **「議員一覧は自前で作らない」を撤回し、議員ページを作る** | 議員の側から見た議会（どんなテーマを掲げて議員になり、議会で何を質問・発言したか）をわかりやすく伝えるため。名簿の情報（会派・連絡先など）は引き続き市議会の名簿へのリンクで済ませ、重複させない |

評価・採点をしない方針は変わらない。

## 載せるもの

1人1ページ。28人全員を同じ形式で載せる。並びは市議会公式の50音順。

| 欄 | 内容 | 出典 |
|---|---|---|
| 基本 | 氏名、会派、市議会の名簿へのリンク | 市議会「50音順議員名簿」 |
| 掲げたテーマ | 本人が掲げているテーマを短くまとめる。分類（タグ）は運営側で付けたと明記する | 選挙公報（市の選挙管理委員会）を第一に。無ければ本人HP・選挙ドットコムの本人登録欄・本人Xのプロフィール。出典と確認日を必ず書く |
| 議会で取り上げたテーマ | 一般質問・代表質問の項目（会期ごと）と会議録へのリンク | 会議録（kaigiroku.net） |
| 質疑した議案 | 本会議・委員会で質疑した議案と、その議案ページへのリンク | 会議録 |
| 会派の賛否 | 所属会派の賛否（意見が分かれた議案のみ） | 市議会だより8面。**会派単位の記録であることを明記する** |
| 本人の発信 | HP・Xへのリンク（本人のものだけ） | 別途作成済みの「議員の公開X・HP一覧」 |

### 載せないもの

- 発言回数・質問数・出席率などの数や、それによる並べ替え・ランキング
- 運営側のコメント、要約による評価、「掲げたテーマ」と「質問したテーマ」の一致・不一致の判定（並べて見せるだけにする）
- 応援アカウント・報道・切り抜き動画など、本人以外の発信
- 見つからない情報は空欄（「公開情報なし」）にし、推測で埋めない

## 議長の補足

議長のページには、次の文を必ず表示する。

> 議長は、議会の運営と中立を保つため、慣例として一般質問を行わず、採決にも加わりません（可否同数のときを除く）。そのため、一般質問や賛否の記録が少なくなります。

議長が交代したときは、在任期間ごとにこの補足を付ける（前議長の在任中の記録が少ないことも分かるようにする）。

## 選挙期間中の扱い

| 選挙 | 扱い |
|---|---|
| 立川市議会議員選挙（一般選挙・補欠選挙） | 告示日から投票日まで、**議員ページ全体を閉じる**（新人候補者にはページが無く、現職だけが目立つため） |
| 市長選・都議選・国政選挙などに現職の市議が立候補する場合 | その議員のページだけを閉じる |

- 閉じている間も、議案・賛否・会議録へのリンクなど議会の公式記録は表示する
- 閉鎖中の表示：「選挙期間中（○月○日〜○月○日）は、公平のため議員紹介ページを公開していません。議会の記録（議案・賛否・会議録）は引き続きご覧いただけます。」
- 告示日より前から閉じるか（例：任期満了の○か月前から）は、次の市議選（任期満了は2030年6月）までに決める
- 公職選挙法の扱いに不安があれば、立川市選挙管理委員会に確認する

## データの取り方（会議録）

- 会議録検索システム kaigiroku.net、立川市の `tenant_id` は 368（API は `docs/20261002_1800_議案解説の書き方ルール.md` 10章を参照）
- 発言者は発言ごとに記名されている。本会議は「１８番（浅川修一君）」、委員会は「委員（若木早苗君）」の形
- 一般質問は冒頭で「第１に、○○について」と項目を読み上げる形なので、テーマを機械的に拾える
- 議案への質疑は、議題（日程）の直後の発言として議案と結びつけられる
- 委員会の起立採決は「賛成者起立」のみで、誰が立ったかは記録されない（議員単位の賛否は作れない）

## 時期の注意

- 2026年6月に改選。公開済みの会議録は令和8年第2回定例会（5月）までで、どちらも**改選前**
- 改選後の最初の議会（第3回、9〜10月）の会議録はまだ公開されていない（2026-11-27時点）
- そのため、新人や前期にいなかった議員は、第3回の会議録が出るまで「議会で取り上げたテーマ」が空になる。試作は前期から続けている議員で行い、公開は第3回の会議録が出てからにするのが望ましい

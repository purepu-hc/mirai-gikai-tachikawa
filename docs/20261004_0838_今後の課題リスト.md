## 1. 議案ごとの会派別賛否（優先度：高）

### 調査結果（2026-10-04）

- **立川市議会のサイトに、議案ごとの賛否の一覧ページはない**（議案一覧ページは「議決年月日、結果」まで）
- **「たちかわ市議会便り」に「各議案等に対する賛否」の表が載っている**
  - 例：第342号（令和8年4月25日発行）8ページ … 令和8年第1回定例会分
    - URL：https://www.city.tachikawa.lg.jp/_res/projects/default_project/_page_/001/027/149/342-8.pdf
  - 構成
    - 「賛否態度が分かれたもの」：議案ごとに**議員ごと（会派ごとに並ぶ）**の ○（賛成）・×（反対）。議長は表決に加わらない（※）
    - 「賛否態度が全員一致だったもの」：件名と結果の一覧のみ
  - 会派の略称：公明（公明党）、共産（日本共産党）、立･ネ･緑（立憲ネット緑たちかわ）、ク（自民党クラブ）、国（国民民主党）、安（安進会）、民（自由民主党）、都（都民ファーストの会立川市議会）、自（たちかわ自民党）
  - PDFは文字データあり（スキャンではない）→ 座標つきで文字を取り出せば表を復元できる見込み
  - 第1回定例会で賛否が分かれたのは3件：令和8年度一般会計予算、令和8年度国民健康保険事業予算、国民健康保険条例の一部改正（残り55件・陳情2件は全員一致）
- 市議会便りは年数回発行。定例会の閉会から**1〜2か月遅れ**で載る（第1回：3月24日閉会 → 4月25日発行）
- 平成18年分からバックナンバーあり

### サイト側の準備状況

- DBに `factions`（会派）・`faction_stances`（議案×会派の賛否）テーブルがすでにある（川崎版の仕組み）
- 議案詳細ページ・管理画面に会派の賛否を表示・登録する機能がすでにある
- → **必要なのはデータの取り込みだけ**（画面の新規開発はほぼ不要の見込み）

### 課題・決めること

- [ ] 議員単位で持つか、会派単位で持つか
  - 現在のDBは会派単位。同じ会派で賛否が割れた場合の扱いを決める（例：「一部反対」）
- [ ] 表のセルが会派ごとにまとめられているか（結合セル）を、座標で確認する。議長の列（※）の扱い
- [ ] 「全員一致」の議案は、全会派「賛成」として登録するか、「全会一致」とだけ表示するか
- [ ] 議員名と会派の対応表（会派の構成は改選・異動で変わる）を、議会サイトの「会派・党派」「議員名簿」から作る
- [ ] 取り込みツール：`packages/tachikawa-ingest` に「市議会便りの賛否表 → SQL」を追加（`.claude/skills/voting-pdf` を参考）
- [ ] 第1回〜第3回（令和8年）を取り込む。第3回分は市議会便りの発行待ち
- [ ] 解説の書き方ルールに、賛否の扱い（賛否は事実として表示し、理由づけはしない）を追記

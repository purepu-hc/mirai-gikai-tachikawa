# 立川市議会 更新通知（Google Apps Script）

立川市議会ホームページの更新を毎日チェックして、変化があればメール（とGoogleカレンダー）で知らせるスクリプトです。
みらい議会＠立川市の「議案一覧の取り込み → 解説作成」を始めるきっかけに使います。

- 無料（Googleアカウントだけで動きます。AI・有料APIは使いません）
- 1日1回、決まった時間に動きます

## 何を見張るか

1. 「各定例会・臨時会の概要」から、**新しいほうの年ページ（2年分）** を自動で見つけます
2. その中の **新しいほうから3会期** のページと、その下の各ページ（日程表・議案一覧・請願陳情 など）
3. 「議案一覧」の一覧ページ（`/shigikai/gian/1007177.html`）

ページ本文の **表の各行** と **リンク** を前回と比べ、増えた行を通知します。
新しい会期のページができたときは「【新しいページ】」として通知されます。

## 設置手順（はじめの1回だけ）

1. <https://script.google.com/> を開き、「新しいプロジェクト」を作る
2. プロジェクト名を「立川市議会 更新通知」などに変える
3. 左の「コード.gs」の中身をすべて消して、このフォルダの `Code.gs` の中身を貼り付けて保存（Ctrl+S）
4. 左の歯車（プロジェクトの設定）→「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック
5. 左に出てきた `appsscript.json` の中身を、このフォルダの `appsscript.json` に置き換えて保存
6. 上の関数の選択で **`setup`** を選んで「実行」
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可する
     （「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」）
   - 許可する内容：外部のページの取得、メール送信、カレンダーへの登録、トリガーの作成、メールアドレスの表示
   - 会社や学校のGoogleアカウント（Google Workspace）では、管理者の設定で実行できないことがあります。個人のGoogleアカウントで設置してください
7. 実行ログに「初回の記録をしました」と出れば完了。**次の `RUN_HOUR` 時ごろの実行から**、変化があったときだけ通知が来ます

## 設定を変えたいとき（Code.gs の先頭の CONFIG）

| 項目 | 内容 |
|---|---|
| `NOTIFY_EMAIL` | 通知先。空なら自分のGmail |
| `YEARS_TO_WATCH` | 新しいほうから何年分の年ページを見るか（年明けに前年の会期を取りこぼさないよう 2） |
| `EXTRA_URLS` | 追加で見張るページ |
| `CREATE_CALENDAR_EVENT` | `false` にするとカレンダー登録をやめる |
| `CALENDAR_ID` | 専用のカレンダーに入れたいときにID（カレンダーの設定画面にある）を入れる |
| `RUN_HOUR` | 実行する時刻（0〜23）。変えたら `setup` をもう一度実行（そのときチェックも1回走り、変化があれば通知されます） |
| `SESSIONS_TO_WATCH` | 新しいほうから何会期分を見るか |

## 便利な関数

| 関数 | 用途 |
|---|---|
| `listWatchedPages` | いま見張っているページの一覧をログに出す |
| `checkUpdates` | 今すぐチェックする |
| `resetSnapshots` | 記録を消す（次のチェックは初回扱い・通知なし） |

## 止めたいとき

左の時計アイコン（トリガー）から `checkUpdates` のトリガーを削除します。記録も消したいときは `resetSnapshots` を実行するか、プロジェクトごと削除します。

## しくみのメモ

- ページ本文（`<div id="voice">`）の中だけを見るので、サイト共通のメニューの変更では通知されません
- 前回の状態は、行ごとの短いハッシュとしてスクリプトのプロパティに保存しています（なくなった行は件数だけ通知）
- 通知（メール）が失敗したときは状態を保存しないので、次の実行でもう一度通知されます
- 見張り先から外れた古い会期の記録は自動で消します
- 市のページは年・会期とも新しい順に並んでいる前提です（2026年10月に確認）
- 市のページの構成が変わると、見張り先を見つけられなくなることがあります。そのときは `listWatchedPages` で確認してください
